# BlackWall — живые обои для Windows 10

BlackWall — лёгкое приложение для поиска, скачивания, хранения и установки живых обоев
на рабочий стол Windows. Задумано как альтернатива Wallpaper Engine для слабых ПК:
кадры рисуются прямо в слое рабочего стола (WorkerW), без браузера и лишних процессов,
с ограничением FPS и автоматической паузой.

## Возможности

- **Живые обои**: MP4, WebM, GIF, анимированный WebP. Статические JPG/PNG/WebP
  устанавливаются как обычные обои Windows (через IDesktopWallpaper — на каждый монитор отдельно).
- **Несколько мониторов**: свои обои на каждом, включение/отключение по отдельности,
  схема расположения экранов, обнаружение смены разрешения. Пауза тоже отдельная:
  кнопка «Настроить»/«Пауза» на «Главной» и переключатель на странице «Мониторы» действуют
  только на выбранный монитор; верхняя кнопка «Пауза всех» останавливает все.
- **Поиск в интернете**: Pixabay и Pexels через официальные API. Реальные результаты,
  фильтры по разрешению/формату/длительности/источнику, предпросмотр, скачивание.
- **Рекомендации**: «Популярное», «Новые», «Для вас», «Выбор редакции» — на основе
  реальных ответов API (без выдуманных карточек).
- **Библиотека и избранное**: локальные файлы и скачанные обои, поиск, сортировка,
  сетка/компактный вид, контекстное меню.
- **Импорт по ссылке (TikTok / YouTube / Pinterest)**: отдельная страница и кнопка в библиотеке;
  распознавание обычных и коротких ссылок, метаданные, превью, автор, прогресс загрузки,
  понятные ошибки. Загрузка идёт через `yt-dlp` в фоне, затем FFmpeg определяет параметры
  и при необходимости готовит копию под монитор; оригинал остаётся в `media/imports`.
  Если скачать нельзя (DRM, приватное, возрастное ограничение) — объяснение и импорт файла.
  Скачивай только видео, на которые у тебя есть права: правила платформ не обходятся.
  Скачанный файл проверяется полным декодированием; повреждённый поток при возможности
  автоматически перекодируется, иначе показывается понятная ошибка.
- **Режимы отображения**: «Заполнить экран», «Размытый фон», «Вписать», «Растянуть».
  Режим задаётся для конкретных обоев и может быть переопределён для каждого монитора
  на странице «Мониторы»; остальные мониторы при этом не меняются.
- **Быстрая настройка на «Главной»**: кнопка «Настроить» открывает диалог текущих обоев —
  режим кадрирования, качество (не выше оригинала), ограничение FPS и звук. Для видео
  можно включить/выключить звук и настроить громкость отдельно на этом мониторе.
  Аудиодорожка сохраняется в импортированных видео и в лёгких копиях качества.
- **Объединение видео**: в библиотеке — «Собрать видео». Автоматический режим склеивает
  выбранные ролики по порядку; ручной позволяет для каждого клипа выбрать начальный и
  конечный кадр. У каждого клипа есть миниатюра и предпросмотр с перемоткой, чтобы
  различать видео с одинаковыми названиями. FFmpeg нормализует разрешение/FPS, сохраняет
  звук (или добавляет тишину), готовое видео добавляется в библиотеку и устанавливается как обои.
- **Загрузки**: очередь, прогресс, скорость, оставшееся время, пауза/возобновление,
  отмена, повтор при ошибке.
- **Адаптивное качество**: при нехватке ресурсов BlackWall сам снижает FPS и разрешение
  воспроизведения, а когда нагрузка спадает — постепенно возвращает качество. Для MP4
  один раз готовится облегчённая копия (720p), чтобы снижение разрешения было реальным.
  Переключения не «дёргаются»: нужны несколько секунд плохих замеров, есть пауза между
  изменениями и защита от повторных неудачных повышений. Включается/выключается в настройках.
  Когда автоматическое качество выключено, качество видео выбирается вручную:
  **Оригинал / 1080p / 720p / 480p** (Настройки → Производительность и страница
  Производительность). Нужная копия готовится один раз и кэшируется.
- **Совместный поиск и фильтры**: запрос, категория и все фильтры применяются одновременно;
  изменение запроса не сбрасывает фильтры, изменение фильтров не очищает строку поиска;
  «Сбросить фильтры» очищает только фильтры. Параметры сохраняются до ручного сброса.
- **Производительность**: режимы 15/30/60 FPS, ограничение FPS, аппаратное декодирование
  (D3D11VA при поддержке GPU), авто-пауза в полноэкранных играх, при бездействии и от батареи.
  Показатели CPU/RAM/GPU/FPS — реальные измерения.
- **Трей и автозапуск**: сворачивание в трей, меню управления, запуск с Windows.
- **Интерфейс**: по умолчанию **Aurora** — чистый чёрный фон (#000000), тёмные
  «стеклянные» карточки, Electric Purple (#8B35FF) как основной акцент и Laser Cyan
  (#00C8FF) для отдельных состояний. В «Настройки → Внешний вид» можно выбрать
  **Classic · Premium Dark** — точную старую чёрно-жёлтую/фиолетовую тему — и акценты
  для каждой темы отдельно. Русский и английский языки.

## Дизайн

Основная тема — **Aurora**: чистый чёрный фон, тёмные градиентные карточки, мягкие
границы и свечение, крупная типографика. Основной акцент — Electric Purple,
дополнительный — Laser Cyan; доступны также Hot Pink, Neon Lime и Amber.
В Aurora «Главная» использует большое hero-превью с названием, метаданными и
действиями поверх обоев, «Производительность» — круглые датчики реальной нагрузки,
«Настройки» — категории слева и содержимое справа.
В «Настройки → Внешний вид» переключается тема:
- **Aurora** — новый дизайн (по умолчанию);
- **Classic · Premium Dark** — прежний чёрно-жёлтый/фиолетовый интерфейс с прежней компоновкой.

Акценты запоминаются отдельно для Aurora и Classic, поэтому переключение тем
не сбрасывает выбранный цвет. Данные, обои, БД и API-ключи при смене темы не меняются.

## Запуск

- Двойной клик по ярлыку **BlackWall** на рабочем столе.
- Или `run.bat` в папке проекта.

```bat
run.bat
```

или вручную:

```bat
cd C:\Users\ivano\Documents\BlackWall
"C:\Users\ivano\AppData\Local\Python\pythoncore-3.15-64\python.exe" main.py
```

Если зависимости не установлены:

```bat
"C:\Users\ivano\AppData\Local\Python\pythoncore-3.15-64\python.exe" -m pip install -r requirements.txt
```

Приложение использует Python 3.15 и PySide6 6.12 (проверено на этой машине).
Второй экземпляр не запускается: он просто показывает уже открытое окно.

## Первый запуск

Язык интерфейса — русский по умолчанию (переключается в «Настройки → Общие»).

1. Откройте «Обнаружить» — поиск работает через официальные API источников.
   - Ключ Pixabay уже сохранён в настройках (тот, который вы дали).
   - Pexels: https://www.pexels.com/api/ — при желании создайте аккаунт,
     скопируйте ключ и вставьте в «Настройки → Источники обоев».
2. Ключи хранятся локально в `data/settings.json`, в исходном коде их нет.
3. Найдите обои в «Обнаружить», скачайте и установите на нужный монитор.
   Или добавьте свои файлы: «Библиотека → Добавить файлы» / «Главная → Добавить видео».

## Папки

- `media/library` — файлы библиотеки (можно изменить в настройках);
- `media/downloads` — скачанные обои (можно изменить);
- `media/imports` — оригиналы видео, импортированных по ссылке (не удаляются автоматически);
- `media/optimized` — подготовленные копии под монитор;
- `cache/thumbnails` — миниатюры (очищаются в настройках);
- `logs/blackwall.log` — журнал ошибок;
- `data/blackwall.db` — база библиотеки/избранного/загрузок;
- `data/settings.json` — настройки и API-ключи;
- `backups/` — резервные копии, созданные перед крупными изменениями.

## Управление

- Закрытие окна сворачивает приложение в трей (настройка «Закрывать в трей»).
- В трее: открыть, пауза/возобновление, смена режима производительности, настройки, выход.
- Горячие ограничения: режим 15/30/60 FPS влияет на декодирование и отрисовку.

## Как это работает

Видео декодируется Qt Multimedia (FFmpeg) и рисуется в окно, которое через Win32 API
встраивается в слой WorkerW за иконками рабочего стола. Окно создаётся на каждый монитор
и позиционируется по его координатам. При перезапуске Explorer приложение переприкрепляет
окна автоматически. Статические изображения ставятся штатным API Windows.

## Ограничения

- Живые обои не являются системными: при выходе из BlackWall они исчезают
  (статическое изображение Windows остаётся). Настройка «Восстанавливать обои при запуске»
  возвращает последний набор при следующем старте.
- Некоторые полноэкранные приложения (античиты, эксклюзивный fullscreen) могут перекрывать
  слой обоев — приложение ставит их на паузу.
- На слабом CPU 4K-видео может не успевать: используйте режим «Экономичный» и видео
  в разрешении монитора.
- Импорт по ссылке использует `yt-dlp`; YouTube/TikTok/Pinterest могут требовать вход, менять
  защиту или блокировать загрузку. DRM, приватные и возрастные видео не обходятся —
  BlackWall показывает причину и предлагает импортировать файл вручную.
  У Pinterest поддерживаются публичные видео-пины (`pinterest.com/pin/…`, `pin.it/…`);
  если пин содержит только изображение, приложение предложит импортировать его файлом.
  Скачивайте только видео, на которые у вас есть права; правила платформ не обходятся.
- Быстрая настройка качества/FPS действует на выбранный монитор; глобальные лимиты
  (режим производительности и ограничение FPS) остаются сверху и могут быть ниже.
  Звук по умолчанию выключен — включается в «Настройках обоев» на «Главной».
- Сборка видео выполняется в фоне и нормализует клипы под выбранный монитор
  (кадрирование, разрешение, FPS); длинные ролики обрабатываются заметное время.
